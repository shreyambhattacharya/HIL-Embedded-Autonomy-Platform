# Milestone 5A evidence

The canonical committed evidence is the compact summary/metrics and safety records in this directory:

- `software_open_square_summary.json`
- `software_open_square_metrics.json`
- `stm32_open_square_summary.json`
- `stm32_open_square_metrics.json`
- `software_obstacle_stop.json`
- `stm32_obstacle_stop.json`
- `software_stale_lidar.json`

The `local/` directory is intentionally ignored. It is for raw logs and individual run files generated while reproducing the evidence. Per-run JSON files matching `*_run_*.json` are also local-only. The aggregate files were generated by the Milestone 5A runner and evaluator described in [docs/milestone_05a.md](../../docs/milestone_05a.md).

Ground-truth data is evaluation-only: it is used to align and measure scenarios, never as an autonomy control input.
